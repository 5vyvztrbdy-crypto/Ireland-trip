JOYCE IRELAND TRIP COMPANION

Open index.html in a web browser to preview the app.

Best iPhone setup:
1. Host this folder on any static host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the HTTPS address in Safari.
3. Tap Share > Add to Home Screen.
4. The itinerary shell, guide text, notes and checkmarks work offline after the first visit. Live map tiles and navigation links require internet.

Editing:
- Open app.js in a text editor.
- The itinerary is the “trip” array at the top.
- Change times, names, descriptions or coordinates as needed.
- Reservation confirmation numbers are intentionally not guessed. Store them in “My Trip Notes” inside the app.

Privacy:
- This version has no account, analytics or server database.
- Notes and completed-stop checkmarks remain in the browser on the device.
