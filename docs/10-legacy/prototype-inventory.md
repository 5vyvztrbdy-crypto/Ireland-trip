# Prototype Inventory

## Current implementation

`index.html` is a 219-line, self-contained early prototype with embedded HTML, CSS, and JavaScript. It includes:

- a Joyce Journey splash screen and promise;
- Today, Journey, Reservations, Journal, and Heritage views;
- seven hard-coded travel days;
- stops, timing guidance, food suggestions, and Google Maps search links;
- a rental-car/flight timing alert;
- Pause and random “Surprise Me” interactions;
- local browser storage for notes and journal records;
- journal JSON download;
- ratings, memories, favorite moments, an unexpected-joy flag, and photo-count capture.

No backend, build configuration, automated tests, structured data files, documentation, or deployment configuration existed at inspection time. This inventory is implementation evidence only.
