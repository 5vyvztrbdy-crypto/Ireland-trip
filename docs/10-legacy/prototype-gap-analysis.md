# Prototype Gap Analysis

| Current implementation | Confirmed product direction |
|---|---|
| Itinerary-centered interface | Full planning-to-publishing lifecycle |
| Duplicated hard-coded reservation text | One canonical reservation source |
| No provenance or confirmation | Retained sources and traveler-confirmed critical facts |
| Google Maps search links | Geographic and temporal Journey Perspective |
| Random generic “Surprise Me” | Explainable, route-aware Unexpected Joys |
| Basic journal | Story Moments, Campfire, and Story Engine |
| Stores selected-photo count only | Bulk photo/video workflow with retained source media |
| No video destination | Video as private memory and Living Album content |
| Journal-only export | Export of all traveler-owned source material |
| Browser storage described as private | Explicit production privacy and security model required |
| No Album workflow | Cached sample, rough draft, traveler editing, and publishing |
| No print abstraction | Publisher-independent composition and adapters |
| Buttons may demonstrate intent | Working-capability definition of done |
| No delivery infrastructure | Documentation, tests, Git, deployment, and daily reviews |

Where the prototype conflicts, preserve it until migration is authorized and use the canonical brief as future direction.
