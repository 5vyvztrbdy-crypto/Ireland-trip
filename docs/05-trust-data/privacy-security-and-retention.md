# Privacy, Security, and Retention

## Confirmed constraints

Source material belongs to the traveler, must be exportable, and must not be silently overwritten. Living Album links should resolve to a specific intended memory rather than expose a camera roll.

## Current implementation

The prototype stores notes and journal data in browser `localStorage` and describes notes as private on the device. That is implementation evidence, not a validated privacy or security guarantee.

## TBD

Authentication, encryption, access control, consent, GPS privacy, media visibility, retention, deletion, backups, breach response, Living Album authorization, and legal compliance require explicit decisions before production claims are made.
