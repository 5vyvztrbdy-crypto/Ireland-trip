# Confirmation and Provenance

## Confirmed

Original reservation images or documents should be retainable. Extraction converts a source once into structured draft data; it should not repeatedly analyze the screenshot. Travel-critical fields require traveler confirmation.

## Planned architecture

Each derived fact should identify its source, extraction event, current confirmation status, traveler corrections, and downstream projections. Source facts, traveler-authored content, and AI drafts should remain distinguishable.

Field taxonomy, confidence thresholds, correction audit behavior, and retention rules are **TBD**.
