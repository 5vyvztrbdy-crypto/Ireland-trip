# User Ownership and Export

## Confirmed

Travelers own their underlying data. Photos, Campfire entries, notes, reservations, reviews, GPS information, Story Moments, and other user-created source material must be exportable without purchasing a Storied Album.

Payment applies to the integrated creative publishing product, not retrieval of the traveler’s memories.

## Current implementation

The prototype exports journal JSON only. Private notes, itinerary data, reservations, media, GPS context, and full source packages are not exported. Selected photos are not retained.
