# Album Publishing Pipeline

## Planned architecture

Canonical journey and story sources → rough first-draft composition → traveler editing and approval → publisher-independent final composition → digital rendering and/or publisher adapter → manufacturing and fulfillment.

Living Album marker generation binds an approved page placement to exact digital media. Partner adapters should isolate external printer formats and capabilities.

Rendering stack, proofing, color management, bleed/layout validation, payments, order state, fulfillment events, reprints, and failure recovery are **TBD**.
