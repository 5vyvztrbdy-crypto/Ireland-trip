# Media Pipeline

## Planned architecture

The media pipeline should accept bulk photo/video input, preserve source assets and metadata, generate non-destructive working derivatives, help select meaningful content, associate media with Story Moments, and prepare digital and print outputs.

Living Album derivatives must resolve to a specific approved memory. Video is handled as private journey memory rather than assumed social content.

Import sources, supported codecs, transcoding, checksums, deduplication, storage, privacy, thumbnails, 360° support, and export are **TBD**.
