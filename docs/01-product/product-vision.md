# Product Vision

## Confirmed

Storied Journey is a travel companion that helps people plan extraordinary journeys and preserve the stories they will treasure forever. Its promise is: “Every journey deserves an epic plan and an unforgettable story.”

It combines planning, in-journey guidance, memory capture, storytelling, editing, and publishing. It is not primarily an AI travel planner. Development works backward from the Storied Album: every major capability should be evaluated partly by whether it improves the eventual story.

The core loop is repeated family use across meaningful journeys, not a one-time itinerary transaction.
