# Media Workflow

## Confirmed

Photo Dump → Select What Matters → Add Words → Align Photos to Moments and Feelings → Build First Draft → Traveler Edits → Publish.

The system accepts a large photo and video collection rather than requiring perfect organization during travel. Short personal videos receive a lasting private purpose. Video is treated as memory, not social-media content.

## Planned architecture

Import should preserve source media and metadata, avoid destructive edits, and support association with specific Story Moments. Selection and Album placement are separate from source ownership. Storage, deduplication, supported formats, processing, and export packaging are **TBD**.
